# Ramos Project 1 — Personal Portfolio Website

A responsive personal portfolio website built with HTML and CSS.

## Folder structure

- `index.html` — main webpage
- `styles/style.css` — website styles
- `assets/profile.svg` — replaceable profile illustration

## Before publishing

1. Replace the sample email and GitHub username in `index.html`.
2. Replace `assets/profile.svg` with your own profile picture if required. If you use a different image filename, update the `<img>` path in `index.html`.
3. Review the About Me, Skills, and Projects sections and edit anything that does not describe you.

## Run locally

Open `index.html` in a web browser.

## Git and GitHub

Open a terminal inside this folder and run:

```bash
git init
git add .
git commit -m "Create portfolio project structure"
```

Create a new empty GitHub repository named `ramos-project-1`, then connect and push:

```bash
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/ramos-project-1.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username.

## GitHub Pages

1. Open your repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub Pages to publish the site. Your URL will look like:
   `https://YOUR-USERNAME.github.io/ramos-project-1/`
